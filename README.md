# 週末清掃確認

民泊運営向けの単一ページアプリ。予約CSVと清掃タスクCSVを読み込み、指定した週末（土・日）の空室部屋と、その日曜に同じ建物へ来る清掃スタッフを一覧化します。

## 使い方
1. `index.html` をブラウザで開く（GitHub Pages公開時はトップURL）。
2. 「予約CSV（Booking_*.csv）」と「清掃タスクCSV（cleaning_tasks_*.csv）」をドロップ。
3. 「対象の土曜」を選ぶ。
4. 3区分（🟢土日 / 🔵土曜のみ / 🟡日曜のみ）の空室一覧が表示。Excel / JPEG 出力可。

## 判定ルール
- 空室：状態が「確認済み」または「ブロックされた」の予約がその夜に無い部屋。夜N占有＝チェックイン≤N＜チェックアウト。システムキャンセルは空室扱い。
- クリーナー：対象「日曜」当日に同じ建物（部屋名の頭で判定・08と10代行等は統合）を清掃するスタッフのみ。無ければ「出勤予定なし」。

## 特徴
- 完全ローカル処理。CSVは外部送信されません（ブラウザ内で完結）。
- 依存ライブラリなしの単一HTML。
