# 週末清掃確認

民泊運営向けの単一ページアプリ。予約CSVと清掃タスクCSVを読み込み、指定した週末（土・日）の空室部屋と、その日曜に同じ建物へ来る清掃スタッフを一覧化します。

- 公開URL: https://scissors-estate.github.io/week-vacancy-app-/
- ホスティング: GitHub Pages
- 構成: `index.html` 1ファイルのみ（約800行・依存ライブラリなし）

## 使い方
1. `index.html` をブラウザで開く（GitHub Pages公開時はトップURL）。
2. 「予約CSV（Booking_*.csv）」と「清掃タスクCSV（cleaning_tasks_*.csv）」をドロップ。
3. 「対象の土曜」を選ぶ。
4. 3区分（🟢土日 / 🔵土曜のみ / 🟡日曜のみ）の空室一覧が表示。Excel / JPEG 出力可。

## 判定ルール
- 空室：状態が「確認済み」または「ブロックされた」の予約がその夜に無い部屋。夜N占有＝チェックイン≤N＜チェックアウト。システムキャンセルは空室扱い。
- クリーナー：対象「日曜」当日に同じ建物（部屋名の頭で判定・08と10代行等は統合）を清掃するスタッフのみ。無ければ「出勤予定なし」。

## 特徴
- 完全ローカル処理。CSVは外部送信されません（ブラウザ内で完結）。
- 依存ライブラリなしの単一HTML。

## 編集するとき（次に変更したくなった時の手順）

1. GitHub の `index.html` を開き、最新の中身をダウンロード（Download raw file）
2. Claude のチャット「【民泊】週末清掃確認」に `index.html` を添付し、直したい内容を伝える
   - 判定がおかしい時は、実際の予約CSV・清掃タスクCSVも一緒に添付すると原因を特定しやすい
3. Claude が直した `index.html` をダウンロードし、手元のブラウザで開いてCSVを読み込み、動作を確認
4. GitHub のリポジトリで **Add file → Upload files** から `index.html` をアップロード → **Commit changes**
5. 1〜2分後に公開URLで確認（変わらなければ Ctrl+F5）

## 注意点

- 必ず **GitHub上の最新の `index.html`** から編集を始める（古いファイルを上げると、他の人の改修が消える）
- 同時に2人以上で改修しない（後からアップした方で上書きされる）
- CSVの列名が変わると読み込めなくなることがある（AirHost等の仕様変更に注意）
- ファイル名は必ず `index.html` でアップロードする（別名だと公開URLに反映されない）

## トラブル時のチェック

- 画面が真っ白・動かない → 直前にアップした `index.html` に誤りがある。GitHub の履歴（History）から1つ前の版に戻す
- 空室が0件／全部空室になる → CSVの列名・状態の表記が変わっていないか確認
- 変更が反映されない → 1〜2分待ってから Ctrl+F5（強制再読み込み）
